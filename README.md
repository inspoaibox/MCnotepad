# MCnotepad

MCnotepad 是一个原生 Win32 C++ 文本编辑器，目标是比传统编辑器启动更轻、工作区更清晰，并且不会丢失未保存的内容。

## 功能

**编辑与标签**
- 标签重命名（`F2`、双击标签或右键）：未保存的新标签修改名称，已保存的文件直接在磁盘上改名
- 多标签页：未保存的标签显示琥珀色圆点，悬停时变为关闭按钮；中键关闭，双击空白处新建
- 标签右键菜单：关闭、关闭其他标签、关闭右侧标签、复制文件路径、在资源管理器中显示；悬停显示完整路径
- 单实例运行：再次打开文件（例如在资源管理器中双击）会交给已打开的窗口；同一个文件已打开时直接切换到该标签
- 查找、替换、全部替换：支持区分大小写、全字匹配、向上查找，到末尾自动从头继续；“全部替换”可一次撤销
- `F3` / `Shift+F3` 重复上一次查找；打开查找框时自动填入当前选中的文字
- 跳转到行（`Ctrl+G`）
- 粘贴时只取纯文本，不会带入网页或 Word 的字体和颜色
- 自动换行；行号栏与文字逐行对齐，自动换行时按真实行编号，并高亮当前行
- 四套主题（深色、浅色、护眼绿、暗夜蓝）；菜单栏、下拉菜单、标题栏和滚动条都跟随主题
- 工具栏按功能分组，每个按钮都有悬停提示；行号、自动换行开启时按钮高亮，无法撤销/重做时按钮变灰
- 支持高 DPI 和不同缩放比例的多显示器

**编码与换行（每个文件独立）**
- 打开时自动识别：UTF-8、UTF-8 BOM、UTF-16 LE、UTF-16 BE、ANSI（系统代码页，例如 GBK）
- 自动识别换行符：CRLF、LF、CR
- 保存时保持文件原来的编码和换行；可在“编码”菜单或工具栏中修改
- 按 ANSI 保存时，如有无法表示的字符，会先提示改用 UTF-8
- 状态栏最左侧显示保存状态（未保存 / 已自动备份 / 已保存），以及行列和选中字数；右侧的编码、换行、语言可以直接点击切换

**语言与工具**
- 自动识别 25 种语言和文件类型：按扩展名、文件名（如 `Dockerfile`、`.env.production`、`.gitignore`，并忽略 `.example` / `.sample` / `.template` 等后缀）以及内容（如 `#!/bin/bash`、`<?xml`）判断，也可以在“语言”菜单或状态栏中手动指定
- 类似 VS Code 的语法着色：关键字、类型、字符串、数字、注释、函数、属性 / 键名、常量、标签等使用不同颜色，深色和浅色主题各有一套配色
  - 代码：JavaScript、TypeScript、C/C++、C#、Java / Kotlin、Go、Rust、Python、PHP、SQL、Shell、PowerShell、批处理
  - 标记与配置：HTML（含内嵌的 `<script>` / `<style>`）、XML、CSS / SCSS / LESS、JSON、YAML、INI / TOML / `.env`、Markdown（含代码块）、Dockerfile
  - 数据：CSV / TSV 按列着色，日志按 ERROR / WARN / INFO 级别着色，Diff / Patch 标出增删行
- 只给可见区域着色，滚动时再补，打开大文件不卡；输入停顿后自动更新，不影响撤销；超过 2 MB 的文件不做着色
- 格式化 JSON（`Ctrl+Shift+F`），可以用 `Ctrl+Z` 撤销
- 运行当前文件（`F5`）：`.bat` `.cmd` `.ps1` `.py` `.js` 会在新的控制台中运行；`.html` 用默认浏览器打开

**文本处理**（“编辑”菜单或编辑区右键菜单；有选中时处理选中内容，否则处理全文）
- 处理结果默认不覆盖原文：可在“处理结果输出到”中选择“输出到新标签（原文不变，默认）”、“插入到原文下方”或“替换原文”；开启预览时，也可以在预览窗口中直接选择这三种方式
- 行处理：合并为一行（直接 / 空格 / 自定义连接符）、每 N 行合并、按分隔符拆分为多行、在指定字符（如 。！？）后换行、按长度换行、删除空行、合并连续空行、删除重复行、排序、反转、每行添加前缀或后缀、添加行号
- 空格、符号与大小写：去除行首 / 行尾空白、合并连续空格、删除所有空格、制表符转空格、清除不可见字符（零宽字符等）、大小写转换
- 中文处理：汉字转拼音（带声调 / 不带声调 / 首字母；默认在每行中文下方添加一行拼音并保留原文，也可只输出拼音；多音字按词语判断）、简繁转换（按词语判断，如“头发”→“頭髮”、“干燥”→“乾燥”）、全角 / 半角互转、中英文标点互转
- 开发者工具：格式化 JSON、Base64 编码 / 解码（UTF-8）、URL 编码 / 解码、正则表达式替换（支持 `$1` 分组引用、区分大小写选项）
- 提取到新标签：邮箱、链接、IP 地址、数字、包含关键词的行、指定列（按分隔符），原文不变
- 处理前预览：执行前显示修改前后的差异（删除的行标红、新增的行标绿），再选择如何使用结果；可在菜单中关闭预览。替换原文或插入结果后都可以用一次 `Ctrl+Z` 撤销

**在文件中查找 / 替换**（`Ctrl+Shift+F` / `Ctrl+Shift+H`，“搜索”菜单）
- 范围：指定文件夹（多个用分号分隔）、所有打开的文件、当前文件；可搜索文件内容、文件名或完整路径
- 匹配：普通文本（`\n` 表示换行）、区分大小写、全词匹配、正则表达式、任一关键词（OR）、全部关键词（AND）
- 筛选：文件类型（如 `*.js;*.ts`）、是否包含子文件夹和隐藏文件、排除规则（默认排除 `node_modules`、`.git`、`dist` 等）、遵循 `.gitignore`、文件大小上限、最多结果数
- 自动识别 UTF-8、UTF-8 BOM、UTF-16、GBK 等编码，自动跳过二进制文件；不跟随目录符号链接
- 多线程后台搜索，搜索时编辑器照常可用，可随时停止；显示扫描文件数、命中文件数、匹配次数、耗时，以及跳过和出错的文件（点击查看日志）
- 结果显示在底部面板（可拖动调整高度），按文件分组、高亮匹配内容；双击跳转到对应文件的行和列；可筛选、复制、导出 TXT / CSV / JSON，结果很多时分批加载
- 替换前先预览：列出每个文件的修改前后差异，可勾选要修改的文件；默认先备份原文件，可一键撤销上次替换
- 替换时保留文件原有编码和换行符；搜索后被修改过的文件、已在编辑器中打开且有未保存修改的文件会被跳过并说明原因
- 保存最近的搜索内容、替换内容、文件夹和文件类型（“搜索 → 搜索历史”）

**文件与文件夹比较**（“工具”菜单；标签右键“与当前标签比较”；命令行 `MCnotepad --diff 左 右`）
- 双文件比较：左右并排、逐行对齐，删除的行标红、新增的行标绿、修改的行标黄并突出改动的字符；两侧同步滚动
- 可以比较两个文件、当前标签（含未保存的修改）与某个文件，或任意两个标签
- 按块合并：“复制到右侧 →” / “← 复制到左侧”把光标所在（或当前）差异块整体复制到另一侧；`F8` / `Shift+F8` 跳到下一处 / 上一处差异；可忽略空白、交换两侧
- 保存时保留文件原来的编码和换行；来自标签的一侧会写回该标签（可撤销），已打开且未修改的文件会自动重新加载
- 文件夹比较：列出相同、不同、仅左侧、仅右侧的文件（按内容比较，跳过 `.git` 和 `node_modules`），双击打开文件比较；勾选文件后可批量复制到另一侧（覆盖前确认）

**结构化比较（JSON / CSV / YAML）**（比较窗口中的“结构比较”，或“工具 → 结构化比较”）
- 在逐行比较之外按数据结构逐项比较：JSON 按键路径（如 `server.port`、`tags[2]`），CSV / TSV 按首列作为行键、按列名比较单元格，YAML 按键和列表项
- 列出修改、仅左侧、仅右侧的项，可多选后逐项“采用左侧”或“采用右侧”的值，包括新增和删除整个对象 / 行
- YAML 和 CSV 只改动相关的行，注释和排版保持不变；JSON 允许注释和末尾逗号，采用后该侧会按原来的缩进重新排版（注释不保留）

**大日志文件查看器**（“工具 → 日志查看器”；打开超过 100 MB 的文件时也会提示；命令行 `MCnotepad --log 文件`）
- 数百 MB 到数 GB 的日志也能秒开：文件以内存映射方式只读打开并建立行索引，不整体载入内存（1 GB、1260 万行的日志约 3 秒建好索引，占用内存不到 10 MB）
- 按级别筛选（ERROR / WARN / INFO / DEBUG / 其他），按时间范围筛选（自动识别 `2026-11-23 10:30:00`、`2026/11/23T10:30` 等格式），按关键词筛选（多个用 `|` 分隔）；可组合使用，筛选在后台进行
- 按级别着色，堆栈等续行跟随所属日志行的级别；错误关键词高亮（默认 error、exception、fail、fatal、timeout，可修改）
- 实时跟踪：文件增长时自动追加新行并滚动到末尾，文件被截断或轮转时重新建立索引
- `Ctrl+C` 复制选中行；双击某行在编辑器中打开它前后各 200 行；“导出到新标签”导出筛选结果或选中行

**开发者工具箱**（`Ctrl+Shift+D` 或“工具 → 开发者工具箱”，停靠在编辑区右侧，可拖动左边缘调整宽度）
- 直接处理编辑器中选中的内容（“跟随编辑器选中”），结果可复制或一键替换选中内容（可撤销），不用打开浏览器
- JSON 格式化 / 压缩 / 严格校验（指出出错的行和列）、Base64、URL 编码 / 解码 / 解析（拆出主机、端口、路径和查询参数）、JWT 解码（含 exp / iat 时间和是否过期）、时间戳与日期互转（自动识别秒、毫秒、微秒，支持时区）、MD5 / SHA-1 / SHA-256 / SHA-512、正则测试（列出匹配和分组，可预览替换结果）、Unicode 转义、HTML 实体、UUID 生成
- 点“⚙”选择要显示哪些工具；工具箱是否打开、宽度和上次使用的工具都会记住

**会话与恢复**
- 正常关闭、系统重启或关机、意外结束后都会自动恢复工作区
- 恢复标签顺序、活动标签、内容、光标、滚动位置，以及窗口位置和大小
- 编辑内容约两秒内写入恢复快照，写入采用临时文件和原子替换
- 文件在其他程序中被修改或删除时，切回 MCnotepad 会提示重新加载

| `Ctrl+Shift+F` / `Ctrl+Shift+H` | 在文件夹中查找 / 替换 |

## 构建

需要 Visual Studio 2026（MSVC）、Windows SDK 和 CMake 3.24 以上。

```powershell
cmake --preset windows-x64
cmake --build --preset windows-x64-release --parallel 4
```

可执行文件位于 `build/windows-x64/Release/MCnotepad.exe`，运行时需要同目录下的 `resources/`（工具栏图标和简繁词典）和 `dict/`（拼音词典）文件夹。

## 数据位置

```text
%LOCALAPPDATA%\MCnotepad\session.dat          会话与设置
%LOCALAPPDATA%\MCnotepad\recovery\*.snapshot  每个标签的恢复快照
%LOCALAPPDATA%\MCnotepad\running.lock         运行标记，用于检测异常退出
%LOCALAPPDATA%\MCnotepad\search.dat           搜索历史与搜索选项
%LOCALAPPDATA%\MCnotepad\replace-backups\     在文件中替换前的原文件备份（保留最近 10 次）
```

详见 [SESSION_RECOVERY.md](SESSION_RECOVERY.md)。

## 第三方库

- [cpp-pinyin](https://github.com/wolfgitpr/cpp-pinyin)（Apache-2.0）：汉字转拼音，源码和普通话词典位于 `third_party/cpp-pinyin`，构建时词典会复制到程序目录的 `dict/`
- [OpenCC](https://github.com/BYVoid/OpenCC)（Apache-2.0）：简繁转换，库源码位于 `third_party/opencc`，简繁词典（文本格式）位于 `resources/opencc`，转换结果为 OpenCC 标准繁体

## 已知限制

- 在文件中查找暂不支持 DOCX、XLSX、PDF 内容和扫描件 OCR，也没有搜索索引
- `.gitignore` 支持常见写法（通配符、`目录/`、开头的 `/`、`**/`），不支持 `!` 取反规则
- 搜索面板目前固定在窗口底部；快捷键暂不支持自定义
- 正则表达式使用 C++ 标准库（ECMAScript 语法），对超大文件和复杂表达式较慢
- 日志查看器只读，支持 UTF-8 和 ANSI（GBK 等）编码，不支持 UTF-16 日志
- 结构化比较的 YAML 只支持常见的块格式（不支持多文档、锚点和 `{ }` / `[ ]` 行内写法的逐项合并）；写在 `- ` 同一行的键需要在文本视图中合并
